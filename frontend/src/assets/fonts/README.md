# Manrope

Self-hosted variable font for the application interface (weights 200–800).
Latin and Latin Extended subsets from `@fontsource-variable/manrope` version 5.3.0.
Source: https://www.npmjs.com/package/@fontsource-variable/manrope/v/5.3.0
Upstream: https://github.com/sharanda/manrope
License: SIL Open Font License 1.1; see Manrope-LICENSE.txt.

Document designers and stored PDF documents retain their own font settings.
